데이터 현황

공고 데이터는 GitHub Actions가 매일 오전 8시 40분(한국시간) 수출e음·전북 수출통합지원시스템·aT수출종합지원시스템·KOTRA 무역투자24·기업마당(수출 분야)에서 전국 공고를 자동 수집·분석해 갱신합니다. 대상 업종·지역은 공고 제목(예: [경기]·'김제시 ○○'·'화장품')을 먼저 보고, 없으면 상세페이지·첨부 공고문의 지원대상으로 판단합니다. 지역 요건이 있는 공고는 해당 지역 기업에만 추천합니다. 여러 사이트에 올라온 같은 공고(첨부 공고문 본문·파일명·제목·마감일 비교)는 대표 1건만 추천하고 다른 게시처를 함께 표시합니다. 기업 프로필과 추천 결과는 서버로 전송되지 않고 이 브라우저에만 저장됩니다(다른 PC·브라우저에서는 보이지 않으니 엑셀로 백업하세요).
